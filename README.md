# KerjainAplikasi 🚀

**KerjainAplikasi** adalah platform Android yang dirancang untuk menghubungkan Pelajar, Mentor, dan Mitra dalam satu ekosistem pembelajaran dan rekrutmen yang terintegrasi.

## 🌟 Fitur Utama
*   **Pelajar**: Monitoring progres belajar, eksplorasi program magang, dan pengumpulan tugas.
*   **Mentor**: Dashboard penilaian tugas, pemberian feedback, dan monitoring perkembangan pelajar.
*   **Mitra**: Manajemen program pelatihan/magang dan pencarian kandidat terbaik (*Talent Pool*).

## 🛠️ Teknologi
*   **Bahasa**: Kotlin
*   **Arsitektur**: MVVM + Repository Pattern
*   **Backend**: Firebase (Firestore, Auth, Storage)
*   **UI**: Material Design 3 (XML)
